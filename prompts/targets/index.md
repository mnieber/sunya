This directory contains so-called "targets". A target is a set of instructions for writing a particular type of "target" application, such as a Python library.

Every target has an example application that illustrates how the spec_src is used to write the code of that example. When I ask you to work on a target with me, we typically do one the following (we may switch between these task but we never execute them both at the same time):

- Improve the spec_src of the example application
- Improve the source code of the example application, so that it correctly reflects the spec_src and the preferred code patterns
