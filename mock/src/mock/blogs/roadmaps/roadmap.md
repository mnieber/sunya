Roadmap

# Glossary

Blog: a weblog
BlogPost: a post within a weblog

# Milestones

## MS1: A user creates a blog

1.  The user visits the blogs route and presses the create-blog button.
2.  The user fills out the create-blog form
    1. They enter the name and description
    2. They press Save to create the blog

## MS2: A user creates a blog-post

1.  The user visits the blogs route and opens one of their blogs.
2.  The user presses the create-blog-post button
    1. They enter the title and content.
    2. They press Save to create the blog-post
3.  The backend checks if blogs and blog-posts do not contain forbidden words.

## MS3: A user edits and deletes a blog-post

1.  The user visits the blogs route and opens one of their blogs.
2.  The user selects a blog-post and presses the edit-blog-post button.
    1. They use the form to update the blog-post and submit the form.
3.  The user selects some blog-posts and presses the delete-blog-posts button.
