# General instructions for writing specs

## The process of creating technical specifications

The creation of a technical specification from the roadmap happens separately for the frontend and the backend. Therefore, when I ask for your help in creating a technical specification, I will always mention if this is for the frontend or the backend.

The technical specification contains two sets of files:

- a set of module specification Python files
- a set of scenario Python scripts

The module specification files define mock code-units. These mock code-units are referenced in the scenario to describe the implementation of a workflow in a roadmap milestone.
