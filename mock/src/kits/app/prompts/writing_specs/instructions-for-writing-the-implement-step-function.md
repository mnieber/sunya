# Instructions for writing steps.py files

When writing a steps.py file, please follow the example in the blogs/backend/scenarios/ms1_a_user_creates_a_blog/steps.py file.

## Purpose of implement_step

The purpose of the implement_step function is to create or mutate entities in response to facts that are declared in steps in a scenario.
Based on reading the scenarios, your task is to figure out which cases must be handled in the implement_step function for that scenario.
The entities that are instantiated are imported from the related namespace.py files.
