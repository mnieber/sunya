Roadmap

# Glossary

Blog: a weblog
BlogPost: a post within a weblog

# Milestones

## MS1: A user creates a blog

1.1 The user visits the blogs route and presses the create-blog button.
1.2 The user fills out the create-blog form
1.2.1 They enter the name and description

## MS2: A user creates, edits and deletes a blog-post

1.1 The user visits the blogs route and opens one of their blogs.
1.2 The user presses the new-blog-post button.
1.2.1 They enter the title and contents and submit the form.
1.3 The user presses the edit-blog-post button.
1.3.1 They change the title and contents and submit the form.
1.4 The user selects some blog-posts and presses the delete-blog-posts button.
