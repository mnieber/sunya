# General code generation instructions

## Use of spec files

Code generation is always informed by module spec files. When I ask you to write source code, please find out what the
relevant module spec files are. Also, comment if you think something in the spec file is unclear or missing.

## Use of specific code generation instructions relevant to the code unit

When I ask you to write the source code for a code unit (such as an api view), then a specific set of instructions
for writing such a code unit will be available. If you cannot find the specific intructions, please let me know.
